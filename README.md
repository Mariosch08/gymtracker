# Gym Tracker

Offline-fähige Web-App (PWA) zum Tracken von Workouts.

- PPL-Rotation, Plan-Editor, Übungstausch (nur heute oder dauerhaft)
- Pausen pro Übung, Pausen-Timer, Einstellungen
- Einseitige Übungen (links/rechts), Notizen pro Übung (Sitzeinstellung usw.)
- Ausführung mit Bildanimation, Tipps und Video-Link
- Cardio (Stairmaster, Laufband, Velo …), Körpergewicht, Rekorde, Verlauf
- Alle Daten bleiben lokal auf dem Gerät – Backup/Restore unter ⚙︎ → Daten & Backup

Übungen anpassen: `exercises.js`. Übungsbilder: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Public Domain / Unlicense).
